    Entrar no Sistema RH

    Use o e-mail registado e o seu código de acesso pessoal. O código não sai deste navegador: só é enviada uma chave calculada a partir dele.

    Não tem? Peça ao Superadministrador o link de primeiro acesso: ao abri-lo, os endereços ficam configurados.

    Definir o seu código de acesso

    Está a usar um código temporário. Escolha agora um código pessoal (pelo menos 8 caracteres) que só você conheça.

    Esqueceu o código? Peça ao Superadministrador um código temporário.

    Novo utilizador

    O utilizador é obrigado a trocá-lo no primeiro acesso. Envie-o por um canal diferente do link.

    Acesso pronto

    O link leva os endereços de acesso (secretos): envie-o só à pessoa. O código não volta a ser mostrado.
